MONitimer Ver.0.1.20 試作版
基準: Ver.0.1.19。旧版はそのまま保持。

配置
ZIP直下のファイルをGitHub Pagesの既存配置先へ上書き。
オンラインで右上Ver.ボタンを押して更新してください。

変更点
1. 時計: アラーム操作部分を残した画面の空き高さに合わせて拡大。比率と時計全体の表示を維持。
2. 電卓: ボタンの高さと間隔をアラームテンキーに合わせ、結果表示とボタンを下側に集約。
3. 計算尺: 上に拡大読取窓、下にリング。
   「リング回転」: ドラッグで外リングのみ回転。赤い針は固定。
   「赤い針を移動」: タップまたはドラッグで読取位置のみ変更。リングは固定。
   「内10」「内60」: 赤い針だけを該当する内側目盛りへ移動。
   拡大窓と数値は常に同じ赤い針の位置を参照。
   リングへのタッチだけでは読取位置は変わりません。
   拡大窓や余白の左右フリックで画面移動。リング操作中は画面切替しません。

使い方の例
12×15: 内10 → リング回転で外12を合わせる → 赤い針を移動して内15 → 外18を読み、桁を判断して180。
80km/hで30分: 内60 → リング回転で外80を合わせる → 赤い針を移動して内30 → 外40（40km）。

維持
時計画像・校正座標・三針描画・1秒ステップ、アラーム入力・転送・OFF・Bluetooth通信、普通/時間電卓、3画面切替の各既存処理は変更していません。
Service Workerと更新方式は維持し、キャッシュ名と版番号だけを更新。

確認済み
・JavaScript構文。
・旧版とのコード比較: 時計、アラーム/Bluetooth、電卓計算、3画面切替処理が一致。
・模擬入力: リングタッチ/タップ/ドラッグで赤い針が移動しない。
・赤い針移動と内10/内60操作でリング角度が変わらない。
・対数目盛り: 12×15の外18、80×30/60の外40を数値と実Canvas描画で確認。
・回転に伴う拡大窓の描画更新。
・模擬Bluetooth: 645→06:45、ON転送・読戻し、時刻保持OFF。
・普通電卓の優先順位、時間加算、モード復帰、3画面の端停止。

未確認
Pixel 7実機での表示寸法、親指での操作感、Bluetooth実接続・実読戻し・鳴動、PWAオフライン再起動・更新。
ブラウザ表示の実行確認は環境制限により行えていません。
