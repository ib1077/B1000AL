CASIOアラームと時間計算（MTG-B1000専用）

設置：ZIPを展開し、中の index.html / sw.js / manifest.webmanifest / icon-192.png / icon-512.png をGitリポジトリの公開フォルダへ置き、GitHub Pagesで公開してください。同じフォルダに置けば、リポジトリ直下でもサブフォルダでも動きます。README.txt は配布不要です。

初回はオンラインで公開URLをAndroid Chromeで開き、ページを読み終えてから「ホーム画面に追加」または「アプリをインストール」を選びます。以後の画面起動と時間計算はオフラインでも使えます。時計のアラーム転送はスマホと時計のBluetooth接続が必要です。時計側の長押しも必要です。

更新：変更したファイルを公開したら sw.js の CACHE 名末尾の番号を毎回増やしてください。オンラインで一度アプリを開くと更新が取得され、次の起動から反映されます。送信中の強制再読込はしません。Chromeのサイトデータ削除やシークレットモードではオフライン保存・機器の許可が失われることがあります。

時計選択の許可は公開URLのオリジンごとです。以前ダウンロードしたHTMLや別URLで選んだ許可は引き継がれない場合があります。初回はB1000を機器一覧から選択してください。HTTPSの公開URLで使用してください。
