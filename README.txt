MONitimer Ver.0.1.19 試作版
正本: MONitimer Ver.0.1.18。旧版ZIPは変更していません。

配置: ZIP直下の全ファイルをGitHub Pagesの既存配置先へ上書きしてください。
右上Ver.ボタンで更新します。PWAの初回起動・更新はオンラインで実行してください。

変更点
・時計／電卓／B回転計算尺の3画面。左右フリック、端で停止。
・時計を比率維持で拡大。不要見出しを撤去し右上に更新ボタン。
・確認済み時刻と入力時刻を横長1枠に整理。
・テンキー左下が転送。645で06:45。削除は右下⌫。
・アラームOFFボタンを再配置。既存のOFF送信処理へ接続。
・電卓から計算尺を分離。×を右列へ移動。時間入力の「時:分:秒」は時間モードで有効。
・計算尺のタップ位置を下窓に拡大。外リングの回転と連動。内側の操作は読取基準線の移動。
・リング上ではページ移動しません。拡大窓・読取値・下の余白からフリックで戻れます。
・10:07の金属ベゼル／白背景アイコン（192・512 PNG）。

保持した内容
・時計画像、校正座標、描画処理、端末時刻、1秒ステップ秒針。
・Bluetooth接続・選択・通知・送受信・読戻し処理は正本と一致。
・acceptAllDevicesの既存選択方式、B1000専用判定、再送制御。
・既存Service Workerキャッシュ方式と更新処理。キャッシュ名のみ新版へ更新。
・将来案（下インダイヤル可動、日付変更など）は未実装。

確認済み
・JavaScript構文、HTML ID重複なし。
・模擬DOM/Bluetooth: 645→06:45、有効入力の転送、ON書込みと読戻し、時刻保持OFF。
・模擬DOM: 普通電卓の演算優先順位、時間加算、モード復帰時の状態、3画面移動と端停止。
・実Canvas: 計算尺回転と拡大窓の描画連動。
・時計の03:15:30の三針角度、保存校正座標との一致。
